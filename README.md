# Football Charts R-universe (`ddevetak.r-universe.dev`)

R package universe for [Football Charts](https://www.football-charts.com) — keyless football data, [Dixon–Coles match probabilities](https://www.football-charts.com/predictions), [interactive probability & fair-odds calculators](https://www.football-charts.com/tools/dixon-coles-calculator), and [10,000-simulation Monte Carlo season projections](https://www.football-charts.com/leagues) across 98 leagues.

## Installation

```r
install.packages("footballcharts", repos = c("https://ddevetak.r-universe.dev", "https://cloud.r-project.org"))
```
